# DMO Catalog

Public customer catalog with category filters, favorites, a local-only selection
basket, price estimate, and copy-to-chat text. It has no checkout, online
payment, account login, or customer-data submission to the backoffice.

The published `catalog.json` contains only the product information displayed
on this site. Everything in this repository is public.
Seal sets are published from the backoffice's advertised member lists and
prices. Set availability is a boolean only; the exact inventory is private.
